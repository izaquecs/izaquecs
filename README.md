# Izaque Carvalho

**Desenvolvedor Full Stack · Aplicações web, APIs e sistemas distribuídos**

Desenvolvo interfaces, serviços e integrações com React, TypeScript, Node.js, NestJS e Go. Meu foco é conectar uma boa experiência de uso a uma base técnica clara, observável e sustentável.

## Tecnologias

- **Frontend:** React, TypeScript, JavaScript, Vite e CSS Modules.
- **Backend:** Node.js, NestJS, Go, APIs REST e Fastify.
- **Dados e mensageria:** PostgreSQL, Redis, Kafka, Prisma e Drizzle ORM.
- **Infraestrutura e observabilidade:** Docker, Grafana, Loki, Fluent Bit, Prometheus e OpenTelemetry.

## Como penso engenharia

Priorizo escalabilidade, performance, segurança e manutenibilidade. Busco decisões apoiadas em medições, responsabilidades bem definidas e observabilidade desde o desenvolvimento.

## Projeto público em destaque

### [Grafana + Loki + Fluent Bit](https://github.com/izaquecs/grafana-loki)

Ambiente com Docker Compose para coleta e centralização de logs com Fluent Bit e Loki, e consulta no Grafana. Inclui um exemplo de envio de logs via UDP em Node.js.
